EUROPA CRM - JOB / CONSULTANT / SUBMISSION AUTOMATION

Implemented incrementally without redesigning the application or changing the existing matching formula.

Key behavior:
- Jobs remain shared/readable by every authorized Bench Sales user.
- Job creator and Super Admin retain edit/delete control.
- Every Job automatically creates and synchronizes one Requirement for the existing matching engine.
- Submission requires a linked Consultant and Open Job.
- Consultant and Job values populate automatically.
- Match percentage/details are calculated and stored automatically.
- Duplicate active Consultant + Job + Vendor submissions are blocked.
- Closed, expired and zero-vacancy Jobs cannot accept submissions.
- Visa, experience and maximum-rate validations run on the backend.
- Existing snapshot fields, reports, dashboards, search and downstream Interview/Offer/Placement workflow remain compatible.

Run migration:
  cd backend
  npx --no-install prisma generate
  npx --no-install prisma migrate deploy
