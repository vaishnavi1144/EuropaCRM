# Functional Automation UI Update

## What changed

- Removed the decorative **End-to-End Automation** workflow strip.
- Removed the explanatory **Automatic Job Matching / Automatic Consultant Matching** banner.
- The automation itself remains functional through the green sparkle action in Jobs and Bench Consultants.
- Clicking the sparkle still performs live matching using the existing backend matching service and opens the inline recommendation table.
- One-click **Submit Resume** and **Submit Anyway** continue to create and link workflow records.
- Insight cards such as **Consultants by Visa** and **Consultants by Notice Period** now display above the records table instead of in a narrow right sidebar.
- The same above-table insight layout is applied consistently across CRM modules.

## Functional workflow

1. Open a Job or Bench Consultant row.
2. Click the green sparkle action.
3. Live recommendations are calculated and displayed below the records table.
4. Select **Submit Resume** or **Submit Anyway**.
5. The submission is linked to Job and Consultant and continues through Interviews, Offers, and Placements using the existing workflow services.

No decorative workflow text is required for the automation to run.
